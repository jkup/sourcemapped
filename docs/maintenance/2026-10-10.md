# RM-12: maintenance pass, 2026-10-10

Baseline: `2705259a0c61debaa060ef1d7b7ec8150eb3dac4`. This is a codebase maintenance record, not another graded agent trial. Scope: confirmed bugs, packaging reliability, brittle shared metadata/error handling, and documentation drift. No new product feature, dependency, live scan or release.

## Findings and changes

- **Inherited lookup:** `src/file.constructor` was reported with language `function Object() { [native code] }`. Own-property lookup now treats it as an unknown extension. A regression covers constructor/case variants and count invariants. The bug existed in the original MVP.
- **Offline packaging timeout:** the full baseline check passed 130 tests but its npm-pack child timed out at 15 seconds; an isolated retry did too. A controlled four-run experiment alternated npm update notifier on/off using fresh temporary caches. Notifier-on runs both reached a 4-second timeout despite complete tarball JSON; notifier-off runs finished in 443/524 ms. Disable that unrelated background check explicitly for offline packing, retain the finite timeout, and include captured stdout/stderr in child-failure diagnostics. No test was skipped or timeout increased.
- **Fragment cache identity:** different `#fragment` map references fetched the same HTTP resource separately, spending budget. A four-request fixture failed with one checked/one limited map before the fix, then passed with two checked relationships and one map fetch. Cache keys now omit fragments while report linkage retains them.
- **Package identity:** CLI version and HTTP User-Agent read the package manifest through one module relative to its file location, including installed packages. No separately maintained runtime version literals.
- **Terminal polish:** aligned help descriptions and corrected singular entry, path, mapping and asset counts; inspected the installed command's output.
- **Structured errors:** bundle/map `errorCode` and bundle `httpStatus` preserve typed retrieval evidence. Rendering distinguishes a received HTTP 429 from later pre-request origin pauses without interpreting prose. See [compatibility decision](../decisions/0005-structured-retrieval-evidence.md).
- **Parsing/test boundaries:** trailing map-reference extraction now walks lines backward without allocating an array for every line of an untrusted bundle. Existing extraction semantics and newline-heavy regression cases pass. Scan/render fixtures assert unexpected requests outside the scanner's catch boundary so a missing route cannot silently masquerade as an expected fetch failure.
- **Project memory:** roadmap reduced to current state, open acceptance criteria and completion links. Historical detail stays in dated records/Git. AGENTS.md consolidates reusable rules, discourages mandatory rule growth and separates task grades from codebase/product quality. No historic grades were rewritten. `npm run check:docs` is part of `check` and verifies local Markdown file targets offline; a deliberately missing target was rejected in a reversible negative control. Remote URLs, heading fragments and factual accuracy still require review.
