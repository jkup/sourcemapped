# Terminal presentation, 2026-10-10

RM-14 follows the user's screenshot and request for clearer, more enjoyable output. The demo previously forced verbose output and disabled color. It now inherits the terminal, runs concise CLI reports and explains mapped, unmapped and mixed scenarios. Serve mode puts a browser URL near the start and prints a ready message and copyable verbose command at the end.

The renderer leads with a result, uses text plus icons (not color alone), and distinguishes target failure, partial scans, no external scripts, advertised-but-unanalyzed maps and analyzed assets. Cyan highlights results, amber indicates incomplete/unanalyzed outcomes, red indicates target failure and no-reference is neutral. Missing references are not labeled broken. Counts remain asset/map relationships; source entries are not globally unique files. The source-text omission and analysis/scope limits remain visible. Successful HTTP logs stay in verbose mode; failed requests, skips and map limits remain visible by default. Bytes use B/KiB/MiB. JSON schema, scanner behavior and exit semantics are unchanged.
